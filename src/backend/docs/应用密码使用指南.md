# 应用密码功能使用指南

## 🎯 功能概述

应用密码功能提供了**永不过期**的邮箱访问方案，解决了OAuth2 token频繁过期的问题。

### ✨ 优势对比

| 特性 | OAuth2 | 应用密码 |
|------|--------|----------|
| 过期时间 | 1小时（需刷新） | **永不过期** |
| 稳定性 | 需处理token刷新 | **高稳定性** |
| 复杂度 | 复杂的OAuth流程 | **简单配置** |
| 维护成本 | 高（需监控刷新） | **极低** |

## 🚀 快速开始

### 1. 获取应用密码

#### Gmail
1. 登录 Gmail
2. 进入 Google 账户设置
3. 安全 → 两步验证（必须先启用）
4. 应用专用密码 → 生成应用专用密码
5. 选择"邮件"应用，获取16位密码

#### Outlook/Hotmail
1. 登录 Outlook.com
2. 设置 → 查看所有Outlook设置
3. 邮件 → 同步邮件
4. 开启"让设备和应用使用POP"
5. 生成应用密码

### 2. API调用示例

#### 设置应用密码
```bash
curl -X POST "http://localhost:8080/api/protected/app-password/setup" \
-H "Authorization: Bearer YOUR_JWT_TOKEN" \
-H "Content-Type: application/json" \
-d '{
  "email": "user@gmail.com",
  "password": "abcd efgh ijkl mnop",  // 应用密码
  "provider": "gmail"
}'
```

#### 获取邮件列表
```bash
curl -X GET "http://localhost:8080/api/protected/app-password/emails/1?page=1&pageSize=20" \
-H "Authorization: Bearer YOUR_JWT_TOKEN"
```

#### 获取邮件详情
```bash
curl -X GET "http://localhost:8080/api/protected/app-password/emails/1/demo-1@apppassword.local" \
-H "Authorization: Bearer YOUR_JWT_TOKEN"
```

#### 获取文件夹列表
```bash
curl -X GET "http://localhost:8080/api/protected/app-password/folders/1" \
-H "Authorization: Bearer YOUR_JWT_TOKEN"
```

## 🔧 技术实现

### 核心文件结构
```
src/backend/
├── handlers/
│   ├── app_password.go         # 应用密码管理API
│   ├── app_password_email.go   # 应用密码邮件获取API  
│   └── email.go               # 集成应用密码到现有邮件系统
├── integrations/
│   └── app_password_simple.go # 应用密码IMAP实现
├── services/
│   └── app_password_manager.go # 应用密码管理服务
└── main.go                    # 路由注册
```

### 工作流程
1. **密码验证**: 使用IMAP协议验证应用密码
2. **加密存储**: 应用密码通过AES加密存储到数据库
3. **邮件获取**: 直接通过IMAP协议获取邮件，无需处理token
4. **错误处理**: 优雅处理连接失败和认证错误

### 安全特性
- ✅ AES加密存储应用密码
- ✅ 支持TLS/SSL连接
- ✅ 用户权限验证
- ✅ 可随时撤销应用密码

## 🔄 从OAuth2迁移

### 自动迁移API
```bash
curl -X POST "http://localhost:8080/api/protected/app-password/migrate/1" \
-H "Authorization: Bearer YOUR_JWT_TOKEN" \
-H "Content-Type: application/json" \
-d '{
  "app_password": "abcd efgh ijkl mnop"
}'
```

### 迁移后验证
```bash
# 检查账户认证类型
curl -X GET "http://localhost:8080/api/protected/app-password/check/1" \
-H "Authorization: Bearer YOUR_JWT_TOKEN"
```

## ⚠️ 注意事项

1. **前置条件**: Gmail需要先启用两步验证
2. **密码格式**: 应用密码通常为16位，可包含空格
3. **撤销方式**: 在邮箱设置中撤销应用密码会立即断开连接
4. **备份建议**: 建议同时保留OAuth2配置作为备用

## 🐛 故障排除

### 常见错误

#### 连接失败
```json
{
  "success": false,
  "error": "IMAP connection failed: failed to connect to IMAP server"
}
```
**解决方案**: 检查IMAP服务器地址和端口配置

#### 登录失败
```json
{
  "success": false,
  "error": "failed to login with app password: authentication failed"
}
```
**解决方案**: 确认应用密码正确，检查是否启用了IMAP访问

#### 权限错误
```json
{
  "success": false,
  "error": "邮箱账户不存在或无权访问"
}
```
**解决方案**: 确认账户ID正确且用户有访问权限
