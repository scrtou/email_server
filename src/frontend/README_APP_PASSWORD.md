## 🔌 API集成

### 调用的后端接口
```javascript
// 应用密码管理
GET    /api/protected/app-password/providers     // 获取支持的服务商
POST   /api/protected/app-password/test         // 测试应用密码
POST   /api/protected/app-password/setup        // 设置应用密码
POST   /api/protected/app-password/migrate/:id  // 迁移到应用密码
GET    /api/protected/app-password/check/:id    // 检查认证类型

// 邮件获取
GET    /api/protected/app-password/emails/:id              // 获取邮件列表
GET    /api/protected/app-password/emails/:id/:messageId   // 获取邮件详情
GET    /api/protected/app-password/folders/:id             // 获取文件夹列表
```

### 数据流
1. **页面加载** → 检查认证类型 → 更新UI状态
2. **用户操作** → API调用 → 状态更新 → 界面刷新
3. **错误处理** → 用户友好提示 → 引导解决

## 🚀 使用流程

### 新用户设置应用密码
1. 访问 `/app-password` 页面
2. 点击"添加应用密码"按钮
3. 选择邮箱服务商（Gmail/Outlook等）
4. 按照指南获取应用密码
5. 输入邮箱和应用密码
6. 测试连接 → 完成设置

### OAuth2用户迁移
1. 在邮箱账户列表中找到OAuth2账户
2. 点击"应用密码"下拉菜单 → "从OAuth2迁移"
3. 输入应用密码
4. 确认迁移 → 享受永不过期访问

### 查看邮件
1. 在应用密码管理页面点击"查看邮件"
2. 或访问 `/app-password/emails/:id`
3. 浏览邮件列表，点击查看详情
4. 支持搜索、文件夹切换等功能
